# ระบบปรับอากาศห้องผ่าตัด (OR HVAC) — ชุดติดตั้งแบบแอป

ชุดไฟล์นี้ทำให้เว็บแอปติดตั้งเป็นไอคอนบนคอมพิวเตอร์และมือถือได้ เปิดเต็มจอ ไม่ต้อง login และใช้งานได้แม้ไม่มีอินเทอร์เน็ต (หลังเปิดครั้งแรกแล้ว)

## ไฟล์ในชุด
- `index.html` — ตัวเว็บแอป
- `manifest.webmanifest` — ตั้งชื่อแอป ไอคอน และโหมดเต็มจอ
- `sw.js` — เก็บไฟล์ไว้ในเครื่อง เพื่อเปิดได้แม้ไม่มีเน็ต
- `icons/` — ไอคอนแอร์โรงพยาบาล ขนาดต่างๆ

## ขั้นที่ 1: นำไฟล์ขึ้นเว็บเซิร์ฟเวอร์
ต้องวางทั้งโฟลเดอร์ไว้บนเว็บที่เปิดด้วย **https://** (การติดตั้งเป็นแอปใช้ไม่ได้กับไฟล์ที่เปิดจากเครื่องโดยตรง)

**ทางเลือก ก: เซิร์ฟเวอร์ภายในหน่วยงาน**
ให้ฝ่าย IT คัดลอกทั้งโฟลเดอร์ไปไว้บนเว็บเซิร์ฟเวอร์ที่มี https เช่น `https://<เว็บหน่วยงาน>/or-hvac/`

**ทางเลือก ข: GitHub Pages (ฟรี)**
1. สมัคร/เข้าสู่ระบบ github.com แล้วสร้าง repository ใหม่ ตั้งเป็น Public
2. กด "Add file → Upload files" แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ icons) ขึ้นไป กด Commit
3. ไปที่ Settings → Pages → Source เลือก "Deploy from a branch" → branch `main` / root → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

หมายเหตุ: บน GitHub Pages ใครมีลิงก์ก็เปิดได้ ถ้าต้องการจำกัดเฉพาะในหน่วยงาน ให้ใช้ทางเลือก ก

## ขั้นที่ 2: ติดตั้งเป็นไอคอน
**Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
**iPhone / iPad (Safari):** เปิดลิงก์ → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
**คอมพิวเตอร์ (Chrome / Edge):** เปิดลิงก์ → กดไอคอนติดตั้งท้ายช่อง URL หรือเมนู → "ติดตั้ง OR HVAC" แอปจะได้ไอคอนบนเดสก์ท็อปและเมนู Start

แอปจะเปิดเต็มจอจากไอคอนบนมือถือ บนคอมจะเปิดเป็นหน้าต่างแยกที่ไม่มีแถบเบราว์เซอร์ กด F11 เพื่อขยายเต็มจอ

## การอัปเดต
เมื่อได้ `index.html` ฉบับใหม่ ให้อัปโหลดทับไฟล์เดิม และแก้บรรทัดแรกของ `sw.js` จาก `or-hvac-v1` เป็น `or-hvac-v2` (เพิ่มเลขทุกครั้ง) เครื่องที่ติดตั้งไว้จะได้ฉบับใหม่เมื่อเปิดแอปพร้อมอินเทอร์เน็ต

## หมายเหตุ
- ตัวอักษรไทยใช้ฟอนต์จาก Google Fonts ถ้าเปิดครั้งแรกแบบไม่มีเน็ต จะใช้ฟอนต์ของเครื่องแทน
- ตัวเลขในแอปคิดจากห้องสมมติขนาด 6 × 6 × 3 ม. และราคาเป็นค่าประมาณ
